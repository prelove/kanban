# 内部看板 v2.0

[English](README.md) | **中文**

面向团队的现代化知识管理系统。

## 快速开始

1. 在浏览器中打开 `index.html`
2. 连按三次 **Ctrl+E** 解锁管理员模式
3. 点击「Add Card」创建内容
4. 开始整理吧！

## 键盘快捷键

- Ctrl+E（×3）= 管理员模式
- Ctrl+K = 搜索
- F = 闪卡模式
- G = 网格模式
- L = 列表模式
- ← → = 导航（闪卡模式）
- Space = 自动播放

## 功能特性

- 多语言（日本語、中文、English）
- 深色 / 浅色主题
- 闪卡模式
- 实时搜索
- 优先级与标签
- 到期跟踪
- 自动保存

## 卡片类型

1. **URL** - 网页链接（http://...）
2. **Code** - 代码片段
3. **Memo** - 文本备注
4. **List** - 要点列表

## 数据管理

- 每 30 秒自动保存
- 导出为 HTML 文件
- 以 JSON 格式导出 / 导入
- 重置为初始状态

## 项目结构

dashboard/ ├── index.html ├── css/（5 个文件）├── js/（8 个文件）└── data/（示例数据）

## 使用技巧

- 使用 Ctrl+K 快速搜索
- 用 ⭐ 置顶重要卡片
- 使用标签进行分类组织
- 设置到期日期作为提醒
- 切换到闪卡模式（F）进行学习

## 浏览器支持

Chrome、Firefox、Safari、Edge（最新版本）

## 协作与同步（GitHub ↔ Gitee）

本仓库同时存在于两个平台：

- GitHub（主要开发）：https://github.com/prelove/kanban
- Gitee（中国大陆协作）：https://gitee.com/prelove/kanban

协作方式：

- 在任一平台上：功能分支 → Pull Request → 合并入 `main`。请勿直接推送 `main`，请勿强制推送。
- 两条 `main` 分支以增量方式保持同步：拉取对方的最新提交，在本地解决冲突，先推送自己一侧，再将合并结果同步到对方（一次干净的快进）。
- 全量覆盖仅用于备份或一次性初始化，绝不用于日常协作。
